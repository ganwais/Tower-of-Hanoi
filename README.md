# 汉诺塔求解器 (Tower of Hanoi)

## 📖 项目简介
这是我在学习 Java 递归（Recursion）时编写的一个经典控制台程序。它通过递归算法解决了汉诺塔问题，演示了将 n 个盘子从 A 柱移动到 C 柱的完整步骤。

## 🚀 功能特性
- **自动求解**：输入盘子数量 n，自动打印出每一步的移动路径。
- **分治思想**：将“移动 n 个盘子”拆解为“移动 n-1 个盘子”的递归子问题。
- **标准格式输出**：清晰展示每一步的移动轨迹（如 A->C）。

## 💻 技术栈
- **语言**: Java SE
- **核心考点**: 递归方法调用、栈帧理解、分治算法思想。

## ⚙️ 如何运行
1. 找到 `TowerOfHanoi.java` 文件。
2. 运行 `main` 方法，默认求解 5 个盘子的汉诺塔。
3. 如需修改盘子数量，调整 `int n = 5;` 即可。

## 📝 学习收获
- 深入理解了递归的“终止条件”与“信任递归”核心思想。
- 画图推导了递归的压栈与弹栈过程。
